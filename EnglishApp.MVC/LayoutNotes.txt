A helper belongs to the layer of the thing it depends on.
| Helper Type                                               | Depends On                   | Layer                                                         |
| --------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------- |
| String helper, math helper, date helper                   | pure .NET, no external stuff | **Domain** or **Application** (preferred: Application/Common) |
| Validation helper                                         | application rules            | **Application**                                               |
| File/media helper (e.g., image resize, save file, upload) | file system / cloud services | **Infrastructure**                                            |
| HTML helper                                               | MVC / API output             | **Presentation (WebAPI)**                                     |
\
